
# HR Analytics Dashboard – Power BI

 Project Overview
This project focuses on analyzing employee data and understanding workforce attrition using Microsoft Power BI.

The dashboard provides insights into employee demographics, salary distribution, job roles and attrition trends to support HR decision-making.

 Key Performance Indicators (KPIs)
- Total Employees: 1,416
- Total Attrition: 229
- Attrition Rate: 16.17%
- Average Employee Age: 37
- Average Salary: 6.52K
- Average Years at Company: 7.04

 Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

 Dashboard Insights
- Employee attrition analysis by gender.
- Attrition based on education level.
- Age-wise employee attrition.
- Salary slab analysis.
- Attrition based on years at the company.
- Job role-wise attrition analysis.

 Dashboard Preview
 
The HR Analytics Dashboard provides an interactive visualization of employee data and attrition trends.

It highlights key HR metrics such as total employees, employee attrition, attrition rate, average age, average salary and average years at the company.

The dashboard includes visual analysis of:
- Employee attrition by gender and education.
- Age-wise attrition distribution.
- Attrition across different salary slabs.
- Employee attrition based on years at the company.
- Job role-wise attrition analysis.

These visualizations help identify employee attrition patterns and provide meaningful insights into workforce trends.
